# Config的设计架构

配置作为Framework的基础设施，其设计与IOC处于同一层次，IOC负责对象的创建和管理，而配置则负责提供对象所需的参数和环境信息。

## Config分类

Config分为`CoreConfig`、`ModConfig`和`ModelApiConfig`三类：

- `CoreConfig`：核心配置，由Core定义，包含Framework的全局设置和基础配置，如日志、数据库连接等。
- `ModConfig`：Mod配置，由各Mod定义，包含Mod特有的配置项，如功能开关、参数设置等。
- `ModelApiConfig`：模型API配置，由Core定义，包含与模型相关的配置项，如API密钥、模型ID等。

其中，`CoreConfig`和`ModelApiConfig`由Core加载，`ModConfig`由各Mod加载。
