# Oi! Maibot-Core Launcher (OMCL) for Maibot-JE

## 如何使用

> 请确保您的系统已安装 `21` 或更高版本的Java运行环境（JRE）

使用 `java -jar OMCL-x.x.x.jar` 命令启动 Maibot-JE 启动器，或双击运行该 JAR 文件。

启动器会自行解析依赖并下载运行所需的文件，首次运行时可能需要一些时间，请耐心等待。
